## Arduino Worm Game 

**An interactive Snake-style game played on an 8×8 LED matrix** - control a growing worm with four buttons, eat targets to grow longer, and hear buzzer feedback on each successful collision. Build on Arduino Uno using MAX7219 matrix, featuring smooth tail-following movement, screen wrapping, and random target placement that avoids the worm's body.

**Key Features:**
- 🕷️ Snake movement with dynamic tail tracking
- 🎯 Target relocation avoiding worm body  
- 📈 Unlimited worm growth with collision limit
- 🔊 Audio feedback on target collection
- 🔄 Edge-wrapping navigation
