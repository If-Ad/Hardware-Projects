*🎮 Project Overview*
Arduino Worm Game is a classic Snake-like game built on an 8×8 LED matrix module. Control a growing worm with four buttons, eat targets to grow longer, and hear satisfying buzzer feedback on each successful eat!

*Features*
✨ Worm movement with smooth tail-following animation
🎯 Target relocation that avoids the worm's body
📈 Worm growth with each target eaten (up to configurable max segments)
🔊 Buzzer beep on target collision
🔄 Screen wrapping at edges
🎨 Clean LED matrix display
